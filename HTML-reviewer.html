Quick recap
  • HTML stands for HyperText Markup Language — it structures content on a web page.
  • Elements are written as tags, usually a pair: <p>text</p>.
  • Tags can carry attributes, like <a href="page.html">.
  • Some elements are self-closing, like <img> and <br>.
  • Every page starts with <!DOCTYPE html> and is wrapped in <html>.
