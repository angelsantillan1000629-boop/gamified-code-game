Learn CSS by reading its rules

CSS controls how HTML looks — color, spacing, layout, and more. Pick a difficulty above — each level builds on the last. Every example here is real, working CSS.

Back to: HTML Dragon →

01 Basic syntax easy

A CSS rule has a selector (what to style) and a block of declarations (how to style it). Each declaration is a property, a colon, a value, and a semicolon.

style.cssrule
h1 {
  color: navy;
  font-size: 32px;
}

Linking CSS to HTML

Put your rules in a separate file and link it from the <head>:

<link rel="stylesheet" href="style.css">

02 Selectors you'll use constantly easy

p

Element selector — targets every <p>.

.card

Class selector — targets any element with class="card".

#header

ID selector — targets the one element with id="header".

*

Universal selector — targets everything.

a:hover

Pseudo-class — styles a link only while hovered.

p, li

Comma groups multiple selectors under one rule.

03 The box model medium

Every element is a rectangular box made of four layers, from the inside out: content, padding, border, and margin.

margin
border
padding
content
.box {
  width: 200px;
  padding: 16px;
  border: 2px solid black;
  margin: 24px;
}

By default, width only sets the content box — padding and border add on top. Set box-sizing: border-box to include them instead.

04 Combinators & specificity medium

nav a { /* any <a> inside <nav> */ }
ul > li { /* only direct <li> children */ }
h2 + p { /* the <p> right after an <h2> */ }

When two rules target the same element, the more specific selector wins: IDs beat classes, classes beat element selectors. A later rule of equal specificity overrides an earlier one.

05 Flexbox layout hard

Flexbox arranges children of a container in a single row or column, distributing space between them.

layout.cssflexbox
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
  • display: flex — turns on flexbox for the container.
  • justify-content — spacing along the main axis (usually horizontal).
  • align-items — alignment along the cross axis (usually vertical).
  • gap — space between children, no margins needed.

Grid, briefly

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Grid is better than flexbox when you need control over both rows and columns at once, like a photo gallery.

06 Responsive design hard

Media queries apply rules only when the screen matches a condition, usually a max width — this is how sites adapt to phones.

.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

@media (max-width: 600px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Also worth knowing: CSS variables (--accent: #89b4fa;, used with var(--accent)) let you define a value once and reuse it everywhere.

08 Recap

  • A rule = selector + declarations, each a property: value; pair.
  • Target elements, classes (.name), or IDs (#name).
  • Every box has content, padding, border, and margin, in that order.
  • More specific selectors win; later rules of equal specificity win.
  • Flexbox and Grid handle layout; media queries make it responsive.
  • CSS variables let you reuse a value across the whole stylesheet.
