Quick recap
  • CSS (Cascading Style Sheets) controls the presentation of HTML — colors, layout, spacing, fonts.
  • Selectors target elements: .class, #id, tag, and combinators like div > p.
  • Every element is a box: content, wrapped by padding, border, then margin.
  • The "cascade" resolves conflicts using source order, specificity, and !important.
  • Modern layout tools include display: flex and display: grid for arranging elements.
