Quick recap
  • Java is an object-oriented, class-based language — everything lives inside a class.
  • Every standalone program needs a main method: public static void main(String[] args).
  • Java is statically typed — variables declare their type, like int x = 5;.
  • Code is compiled to bytecode and run on the JVM (Java Virtual Machine).
  • Common primitive types include int, double, boolean, and char.
