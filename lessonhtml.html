Learn <HTML> by reading its source

HTML is the markup language that gives web content its structure. Pick a difficulty above — each level builds on the last. This page is itself written entirely in HTML, so every example is real, working markup.

01 The document skeleton easy

Every HTML page starts from the same skeleton. Nothing shows on screen without it — think of it as the file's table of contents for the browser.

index.htmlskeleton
<!-- 1. Tells the browser this is HTML5 -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <!-- Metadata: not shown, but read by the browser -->
    <meta charset="UTF-8">
    <title>My Page</title>
  </head>
  <body>
    <!-- Everything visible goes here -->
    <h1>Hello, world!</h1>
  </body>
</html>
  • <!DOCTYPE html> — always the first line. Declares HTML5.
  • <html> — wraps the whole document.
  • <head> — info about the page (title, links, meta tags). Nothing here is visible.
  • <body> — everything the visitor actually sees.

02 Elements you'll use constantly easy

<h1> … <h6>

Headings, largest to smallest. Use one <h1> per page.

<p>

A paragraph of text.

<a href="…">

A link to another page or section.

<img src="…">

Embeds an image.

<ul> / <ol> / <li>

Unordered, ordered lists, and their list items.

<div>

A generic box for grouping content.

03 Anatomy of a tag medium

Most HTML content is written as an element: an opening tag, some content, and a closing tag. Attributes live inside the opening tag and add extra detail.

<aopening tag hrefattribute name="page.html"attribute value, in quotes>Click herecontent — what the visitor sees/reads</a>closing tag — note the slash

Self-closing elements

A few elements carry no content, so they don't need a closing tag:

<img src="cat.jpg" alt="A sleeping cat">
<br>
<hr>

04 Attributes medium

Attributes sit inside the opening tag and configure the element. Format is always name="value".

<a href="https://example.com" target="_blank">Visit site</a>

<input type="email" placeholder="you@example.com" required>

Common ones worth knowing: id, class (used by CSS), src, href, and alt.

Nesting elements correctly

Tags must close in the reverse order they opened — like matching brackets.

<!-- ✅ correctly nested -->
<p>Some <strong>bold</strong> text</p>

<!-- ❌ crossed tags — invalid -->
<p>Some <strong>bold</p>text</strong>

05 Semantic HTML hard

Instead of wrapping everything in generic <div>s, semantic tags describe what a section of the page means — which helps screen readers, SEO, and other developers reading your code.

semantic.htmllayout
<header>Site logo and nav</header>
<nav>Main navigation links</nav>
<main>
  <article>
    <h2>Post title</h2>
    <p>Post content…</p>
  </article>
  <aside>Related links</aside>
</main>
<footer>Copyright, contact info</footer>
  • <header> / <footer> — top and bottom of a page or section.
  • <nav> — a block of navigation links.
  • <main> — the primary content, used once per page.
  • <article> — self-contained content (a post, a card).
  • <aside> — tangential content, like a sidebar.

Accessibility basics

A few habits that make pages usable for everyone, including screen-reader users:

<img src="chart.png" alt="Sales rose 12% in Q3">
<button aria-label="Close dialog">×</button>
<label for="email">Email</label>
<input id="email" type="email">

06 Forms hard

Forms collect input and send it somewhere. Every field needs a name so its value gets submitted.

signup.htmlform
<form action="/submit" method="POST">
  <label for="name">Name</label>
  <input id="name" name="name" type="text" required>

  <label for="plan">Plan</label>
  <select id="plan" name="plan">
    <option>Free</option>
    <option>Pro</option>
  </select>

  <button type="submit">Sign up</button>
</form>

Useful type values for <input>: text, email, password, checkbox, radio, date, number.

08 Recap

  • Every page starts with the <!DOCTYPE html> → <html> → <head>/<body> skeleton.
  • Elements = opening tag + content + closing tag.
  • Attributes configure an element and live inside its opening tag.
  • Tags must close in the reverse order they opened.
  • Semantic tags like <main> and <article> describe meaning, not just layout.
  • Forms need a name on each field to submit its value.
